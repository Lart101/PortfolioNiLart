# Post-Implementation Problem Solving
If a problem is encountered after completing the implementation of a plan, do not immediately attempt to guess the fix or make rushed changes. Instead, step back, formulate a clear plan to solve the newly discovered problem, and only implement the fix after the plan is established. Treat post-implementation issues with the same rigor as the initial task.
